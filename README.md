# マニアスタジアム（Phase 1: MVP）

サッカー(欧州リーグ)・NBA・MLB・ボクシングを、順位表・試合結果/日程・
「読み物」(歴史や文化のマニアックな解説記事)で追いかける観戦アプリ（PWA）です。

## Phase 1でできること

- ⚽ サッカー：プレミアリーグ / ラ・リーガ / セリエA / ブンデスリーガ / リーグ・アン / チャンピオンズリーグ の順位表・試合結果
- 🏀 NBA・⚾ MLB：順位表・試合結果/日程
- 🥊 ボクシング：主要カードの試合予定（手動更新）
- 📖 各スポーツに「読み物」タブ：歴史的背景・魅力・現地の空気感を解説する記事

データはESPNの公開API(非公式・キー不要)を利用しています。将来的にAPI仕様が変わる可能性はありますが、
広く使われている安定した情報源です。

まだ入っていない機能（次のフェーズで追加予定）:
NFL・F1・ゴルフの追加、移籍・トレード情報、過去の試合ハイライト動画、現地観戦ガイド

## ボクシング日程の更新について

ボクシングには安定した無料APIが無いため、`src/data/boxingSchedule.json` を手動で更新しています。
最新の日程に更新したいときは「ボクシングの日程を更新して」とMulmoClaudeに頼んでください。

## GitHub Pagesへの公開手順

御蔵島図鑑アプリと同じ手順です。

1. このフォルダをGitHub上のリポジトリ（例: `sports-mania`）にpush する
2. `Settings > Pages` で Source を **GitHub Actions** にする
3. `main` にpushすると自動でビルド＆公開される
4. `https://<ユーザー名>.github.io/sports-mania/` で公開される

APIキーの設定は不要です（ESPNの公開APIはキー不要のため）。
